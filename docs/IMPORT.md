# Excel 导入（T012）

在“数据管理”选择 XLSX、工作表和表头行，逐列映射后预览。仅接受标准无宏 XLSX，8MiB 文件/32MiB 总解压/32表/全文件10000行/64列；旧 XLS、XLSM、加密文件等拒绝。文件只在内存读取，不改原文件、不保存上传文件、不执行公式、宏、外部链接或单元格中的指令。公式只可使用缓存值，明确提示可能过期，用户核对后才能确认；没有可用缓存的必需字段报错。

全国编号与本地物种ID不同。当前物种必需；原始物种、日期、形态、游戏、途径、球种等均不自动推断。表头“姓名”不默认等于昵称；工作表名不默认等于获得游戏；次数/获得方式可作为备注保留，不重建Hunt或虚构计数单位。格式化的Excel日期支持1900/1904纪元，拒绝虚构闰日、含时间的序号；文本日期仅接受YYYY/YYYY-MM/YYYY-MM-DD，精度不补全。不支持的格式需明确值映射或在副本整理，不改原件。

字段支持当前/原始物种（内部ID或全国编号）、形态ID、原始/当前游戏ID、当前位置、获得日期、来源、持有、昵称、性别、性格、特性、球种、等级、备注。重复字段禁止，备注可多列拼接。值映射JSON按目标字段+原值显式转换，如 `{"source":{"交换":"trade"},"original_game_id":{"已核对版本":"1"}}`；游戏ID仅为示意，必须核对本机资料。界面提供当前本地ID/全国编号清单；未收录资料需先通过既有资料导入流程补齐，不能编造映射。

预览无个人记录或批次数据库写入；内存最多3份，30分钟失效，重启失效。表头后所有非空行均显示原行号、原值、规范化输入、错误和警告，不把空白模板自动视为已获得个体。每页50行，默认不选中；只选真实个体，最多500行/批。错误行禁止确认，未选行不写入。未映射非空列会明确警告，确认后原单元格值保存在该行批次溯源中，不静默丢弃。未知字段留空，来源/持有默认unknown。

疑似重复采用当前物种+可空原始游戏+可空获得日期的保守匹配，包含已软删除身份及同表候选；只是预警，不断言相同，不自动覆盖/去重。同种多只允许保留。确认事务内再次核对现有数据；必须显式确认警告。选中行的个体、注册历史、批次和逐行溯源全部事务提交/回滚；无Hunt历史记录直接创建ShinyRecord。批次保留文件SHA256、工作表、映射、选中行号及每行个体ID/原值，便于结果校验。

确认令牌作为幂等键：相同行选择重试返回原批次，改选行拒绝；响应丢失时界面锁定选择，只允许用相同令牌安全重试，不自动再次导入。不要在结果不明时重新预览并重新提交；先核对 `/api/v1/imports/batches` 以及收藏。最多返回最近100个批次；完整归档随数据导出/备份提供。预览清除走discard，确认后的批次不会因此删除。没有自动批量覆盖、回滚删除个体或破坏性恢复操作。

## API

- `POST /api/v1/imports/inspect`：multipart `file`；返回只读工作表/行/单元格，包含公式缓存标志及单元格问题。
- `POST /api/v1/imports/preview`：multipart `file`、`mapping` JSON（sheet/header_row/columns列字母→字段/values字段→原值→显式值）；返回token/到期时间/规范化行/错误/警告/重复候选。
- `POST /api/v1/imports/confirm`：JSON token/rows原行号数组/acknowledge_warnings；返回已提交或幂等重试的batch/rows，逐行关联ShinyRecord ID。
- `POST /api/v1/imports/discard`：JSON token；清除内存预览。
- `GET /api/v1/imports/batches`：最近100个已确认批次；`GET /imports/batches/:id` 查看逐行个体关联与原值。界面可核对批次到个体，个人溯源数据仅本地使用。

错误沿用统一JSON契约；multipart接口拒绝外部网页Origin/跨站请求，服务仍只监听loopback，未开放CORS。反向代理正式部署和多用户认证未授权。

## 真实样本验收与隐私

用户提供的真实工作簿只读检查：15表/6756个存储行，10表识别出本组可验证的表头，共1712个非空候选行。T012首轮隔离测试采用2物种引用夹具，得到7行格式/引用可用、1705行错误、2973提示；T015自审发现该夹具与实际启动种子的覆盖不同，已将可选真实样本测试改为程序同一 `reference.EnsureSeed`（3物种）并重新实际执行，最终为**8行格式/引用可用、1704行错误、2972提示**。

8行不代表确认8只实际个体，可能包含模板行；另外5表未由这组映射覆盖，不能声明完整迁移。两轮原文件SHA256均前后一致、确认导入为零、临时库新增个人个体为0。现有部分物种/游戏种子不足以导入整份收藏；本次完成实际映射/安全预览/错误报告，不宣称真实收藏已迁入系统。

本次真实样本验收不将逐行值或文件指纹写入数据库；原文件/路径和这些数据均不上传GitHub，此文仅记结构/汇总。用户后续主动确认时，批次溯源保存在本地私有数据库。CI只使用运行时生成的匿名XLSX，覆盖XML/ZIP边界、日期/公式、错误定位、重复预警、未知不推断、确认前零写入、事务失败回滚、重复确认与并发出现候选、HTTP和浏览器完整流程。可选本地真实样本检查用 `PST_REAL_XLSX` 环境变量启用 `TestRealWorkbookMappingReadOnly`，默认跳过；只读、不确认、不输出逐行值，日志在仓库外保存。

额外真实样本只读语义检查：8行位于现有资料范围的编号，其姓名缓存与全国编号对应均一致（8/8），支持此映射的语义；仅记汇总，不保存个人行值。
