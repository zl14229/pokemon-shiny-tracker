# Pokémon Shiny Tracker — Data Source Policy V1.1

- 状态：已确定的数据来源策略 + 待技术验证的资料获取与权限细节。
- 版本：2026-10-23，产品范围不变。
- 关联：ADR-016；T006 / T016 / T017 / T026 / T027 / T024。

## 1. 数据源责任矩阵
| 来源 | 首要任务 | 自动获取边界 | 缺失处理 |
|---|---|---|---|
| PokéAPI v2 | 物种、全国编号、形态、进化、多语言名称、部分游戏/遭遇基础数据 | 可按官方规则 GET，必须本地缓存、控制频率，验证实体映射 | 部分资料缺失则未知，不能生成自造资料 |
| 52Poké | 官方中文名称、形态、游戏版获取途径核对 | 先核验接口与许可；遵守 robots.txt、可识别 UA、顺序请求与间隔；默认不自动批量复制正文 | 可先保留手工核验/资料链接 |
| Serebii | 游戏遭遇、锁闪、合法直接获取、方法、条件概率 | 默认人工合规核对与来源链接；自动采集须单独核实授权 | 缺来源则 `unknown` |
| Bulbapedia / Pokémon Database | 第二来源验证、补充背景 | 遵守各来源许可及访问要求 | 冲突标记待审核，不强行覆盖 |
| 官方公告/游戏内资料 | 版本/活动机制、公告时间和限定条件 | 只在许可范围存必要的结构化事实与链接 | 暂不宣称有官方验证 |

## 2. 核心语义分离
| 对象/字段 | 记录什么 | 不等于什么 |
|---|---|---|
| Species / Form | 官方物种及可辨识形态、内部稳定 ID 与外部映射 | 不直接等于游戏中可合法闪光 |
| Game / Version | 单独的游戏版本、DLC/更新适用范围 | 不保证所有目标都有数据 |
| ShinyAvailability | 给定游戏+物种/形态的 `confirmed_available / confirmed_locked / transfer_only / unknown` | 不等于已有具体攻略 |
| PokemonHuntMethod | 游戏+形态+方法+地点+解锁条件及可用性 | 不等于游戏普遍的闪光机率 |
| EncounterRate | 指定来源/地点/条件下的遭遇率 | 不等于目标闪光机率 |
| ShinyOddsRule | 指定游戏、方法、条件、增益、活动时间有效的闪光概率或算法（允许未知） | 不等于任意遭遇通用的概率 |
| SourceEvidence | URL、来源、核对时间、原始外部 ID、批次、核验状态 | 不代表网页许可自动转载 |

## 3. 缓存和更新流程
1. 读取数据源到暂存区并记录来源和批次；失败不中断个人记录功能。
2. 验证全国图鉴编号、形态与游戏映射，校验来源冲突/缺失/版本适用性。
3. 只对已核实数据生成或更新正式本地资料；初期可以使用随程序打包的经过校验的基础种子数据，实现离线启动。
4. 资料更新先出差异报告，事务应用，保留上一个可恢复的数据资料版本。
5. 用户的 Hunt 和 ShinyRecord 不随资料重导入而改变身份、日期、状态或历史关联。
6. 记录每个游戏的资料覆盖程度；Hunt Planner 只读取已核实可直接刷闪的候选池，若资料不完整需要明确提示。
7. 将个人 SQLite 数据、用户图片与媒体资料保存在源码 Git 仓库之外；真实数据备份与资料库快照分别管理。

## 4. 测试矩阵
- 相同物种多个游戏/形态来自不同外部标识：内部映射稳定，导入幂等。
- 中文名缺失/简繁冲突：显示待核实与回退，不擅称官方译名。
- 游戏只有转入 HOME 的途径：不能当作当地合法直接刷闪目标。
- 遭遇概率有值但闪光概率未知：分别展示而不补算。
- 方法条件不同导致概率不同：保留各自范围，不无条件套用。
- 一个源站失效、超时或拒绝访问：个人记录/本地随机候选功能继续可用。
- 上游源站更新形态、游戏/方法信息：差异可预览，可回滚。
- 未知可获取性不进入默认 Planner 候选池；已确认可刷但攻略尚无则允许抽中并提示方法待补充。

## 5. 具体任务归属
- **T006**：基础 PokéAPI 数据适配、校验的物种/部分形态/游戏本地种子、查询接口、缓存和外部 ID 映射。
- **T016**：全国图鉴丰富资料、形态、简繁中文、52Poké 校对、来源映射与数据覆盖状态。
- **T017**：图鉴分母与历史/持有双口径读取经核验的可获取性状态，不依赖联网。
- **T026**：按游戏详细获取方式/地点/锁闪、遭遇率及条件闪光率；官方与多百科交叉核验、资料覆盖度标识。
- **T027**：只用本地已确认合法可直接刷闪的候选、正确处理两种缺失池和多游戏均匀抽样。
- **T024**：经授权且合规的来源同步、差异查看、原子更新、缓存刷新/离线回退、版本回滚。
